# Smart Home Security and Monitoring System

Проект микроконтроллерной системы охраны и мониторинга параметров среды для умного дома.  
Система разработана на базе микроконтроллера ESP32-S3 и предназначена для контроля состояния жилого помещения, отображения информации на TFT-дисплее и формирования звукового оповещения при обнаружении тревожных событий.

## Требуемые библиотеки

Для сборки проекта необходимо установить следующие библиотеки в Arduino IDE:

Adafruit GFX Library

Adafruit ST7789 and ST7735 Library.

DHT sensor library

Adafruit Unified Sensor

SPI

Если проект открыт через Visual Studio Code, библиотеки должны быть доступны в установленной Arduino-среде или через используемое расширение/окружение сборки.

## Описание проекта

Данный проект представляет собой прототип системы умного дома, которая объединяет функции охранной сигнализации и мониторинга параметров окружающей среды. Система считывает данные с датчиков, отображает текущее состояние на дисплее и управляет исполнительными устройствами.

Проект может использоваться как учебный пример микроконтроллерной системы, включающей работу с датчиками, экраном, кнопками, энкодером и звуковой сигнализацией.

## Основные возможности

- измерение температуры и влажности;
- отображение текущего состояния системы на TFT-дисплее;
- обработка нажатий кнопок управления;
- работа с поворотным энкодером;
- обнаружение звуковых событий;
- включение звукового сигнализатора при тревоге;
- индикация режимов работы системы;
- модульная организация программного кода;
- возможность дальнейшего расширения проекта.

## Используемые компоненты

| Компонент | Назначение |
|---|---|
| ESP32-S3 | Основной микроконтроллер |
| ST7789 TFT Display | Отображение информации |
| DHT11 | Измерение температуры и влажности |
| Rotary Encoder | Навигация по интерфейсу |
| Кнопки NEXT/BACK | Управление системой |
| Датчик звука | Обнаружение звуковых событий |
| Активный буззер | Звуковая индикация тревоги |

## Подключение компонентов

| Устройство | Пин ESP32-S3 |
|---|---|
| TFT CS | GPIO4 |
| TFT DC | GPIO16 |
| TFT RST | GPIO15 |
| TFT SCK | GPIO18 |
| TFT MOSI | GPIO17 |
| DHT11 DATA | GPIO5 |
| Rotary Encoder CLK | GPIO7 |
| Rotary Encoder DT | GPIO6 |
| Button NEXT | GPIO9 |
| Button BACK | GPIO10 |
| Buzzer | GPIO14 |

> В проекте используется питание 3.3V и общий GND для всех модулей.
